**Continue Reading** link opens the whole thing.

## Adding a post

Create a new file in `content/blog/` named like `2026-10-20-my-post.md`, give it
a small header, and run `./build.sh`:

```text
---
Title: My Post
Date: 2026-10-20
Description: One line about the post.
Image: my-photo.jpg
---

Post text goes here.
```

Files are listed newest first based on their name, so the `YYYY-MM-DD-` prefix
keeps everything in order.

## Images

Drop an image into `assets/images/` and reference it by name. This page uses a
cover image:

![A diagram from the post](blog-welcome.svg)

You can also link between pages, for example to the
[projects page](projects/index.html) — the build script fixes up relative paths
so links work from any folder.
