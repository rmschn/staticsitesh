## What is this?

This is a small **static** website. There is no database, no server-side code,
and no framework — just HTML, CSS, and a handful of Markdown files that are
turned into pages by `build.sh`.

## Who writes here?

Replace this paragraph with your own story. Anything you can write in Markdown
works: *emphasis*, **strong**, `inline code`, links, lists, images, and quotes.

## What is on the site?

- **Blog** — a running list of posts, newest first.
- **Projects** — the same format, used for things I build.
- This **About** page — the easiest place to edit information about the site.

the top), then run:

